# Website SPPG Bekasi Babelan Bahagia 11 - Gratis

## Isi
- `index.html` = halaman website
- `style.css` = desain
- `script.js` = fungsi menu HP
- `images/menu-hari-ini.webp` = gambar poster menu yang kamu kirim

## Cara mencoba
Klik/buka `index.html` di browser.

## Cara online gratis dengan GitHub Pages
1. Buat akun GitHub di github.com.
2. Buat repository baru, misalnya `website-sppg-bahagia-11`.
3. Upload `index.html`, `style.css`, `script.js`, dan folder `images`.
4. Buka Settings > Pages.
5. Pada Source pilih `Deploy from a branch`.
6. Pilih branch `main` dan folder `/ (root)`, lalu Save.
7. Tunggu beberapa menit. GitHub memberikan alamat website gratis.

## Cara update menu setiap hari
Paling mudah:
1. Siapkan poster menu baru.
2. Beri nama file `menu-hari-ini.webp` atau ubah HTML jika memakai nama lain.
3. Di repository GitHub, buka `images/menu-hari-ini.webp`.
4. Upload/replacement dengan poster baru.
5. Edit tanggal pada `index.html`, bagian `.date-pill`.
6. Commit changes.
7. Website akan otomatis diperbarui setelah GitHub Pages selesai deploy.

Catatan: versi ini gratis dan mudah, tetapi update masih dilakukan melalui GitHub. Untuk admin media yang ingin update tanpa menyentuh kode, langkah berikutnya adalah membuat versi CMS berbasis Google Sheets/Google Drive.
